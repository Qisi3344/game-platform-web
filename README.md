# game-platform-web

小众独立游戏社区原型。当前工作名：**霓核 NEONCORE**。

## 当前功能

- 登录 / 注册（本地 `localStorage` 演示）
- 注册时按物种随机生成像素头像
- 支持猫、狗、狼、豹、龙、鱼、狐狸、兔、鸟、企鹅、蝙蝠、蜗牛、幽灵、史莱姆、机器人
- 选中头像后可单独随机换色
- 游戏区：搜索、排序、发布、编辑、下架、删除、试玩
- 发帖区：分类、点赞、评论、收藏
- 用户中心：作品、收藏、评论、编辑资料、重新生成头像
- 手机 / 平板 / 桌面自适应；手机头像网格为 6 列

## 本地预览

直接用浏览器打开 `index.html` 即可。

演示账号：

- 密码：`demo`

## 说明

当前是纯前端原型，账号和内容保存在浏览器 `localStorage`。后续接正式后端时，需要把用户、游戏、帖子、评论、收藏与头像参数迁移到服务端数据库。
